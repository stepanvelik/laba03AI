# Лабораторная работа: нейросеть для распознавания диапазона

Файл программы: `main.py`.  
Задача: по одному числу `x` ответить **1**, если оно попало в диапазон, и **0**, если не попало.

Диапазоны класса 1:
- от **-0.7** до **-0.5**
- от **0.5** до **0.7**

Во всех остальных точках ответ должен быть 0.

---



Это **полносвязная нейросеть** (многослойный перцептрон). Вход — одно число `x`. Выход — одно число, по которому мы решаем 0 или 1.

Архитектура строго такая, как в задании:

**1 входной нейрон → 4 нейрона скрытого слоя → 2 нейрона второго скрытого слоя → 1 выходной нейрон**

На каждом слое стоит функция активации **гиперболический тангенс** (`tanh`). Она сжимает значение в интервал **от -1 до 1**. Поэтому для обучения удобнее не цели 0 и 1, а цели **-1 и +1**:
- класс 0 (не попали) → цель **-1**
- класс 1 (попали) → цель **+1**

После обучения берём выход сети:
- если выход **больше 0** → отвечаем **1**
- если выход **меньше или равен 0** → отвечаем **0**

Обучение идёт методом **обратного распространения ошибки** (backpropagation). Сеть смотрит на примеры, считает ошибку (MSE) и чуть сдвигает веса в сторону уменьшения этой ошибки. Чтобы шаги были устойчивее, используется **момент** (как «инерция» предыдущих обновлений весов).

Данные сеть не скачивает из интернета. Мы **сами генерируем** точки `x` на отрезке `[-1, 1]` и сами ставим метку по правилу диапазонов. Потом часть точек используем для обучения, отдельно генерируем тестовую выборку.

После обучения программа рисует графики и даёт ввести своё число `x`.

---

## Почему нужен tanh, а не «просто порог»

Без нелинейной активации несколько линейных слоёв схлопываются в одну прямую. Тогда сеть не сможет вырезать **два отдельных окна** на оси `x`.

`tanh` нелинейный: он позволяет скрытым нейронам «включаться» в разных местах оси. Четыре нейрона первого скрытого слоя помогают найти границы интервалов, два нейрона второго слоя собирают эти границы в два «окна», выходной нейрон выдаёт итоговый сигнал.

Производная tanh известна и простая: `1 - tanh(z)^2`. Её используем в `backward`.

---

## Дисбаланс классов 

Если равномерно брать `x` от -1 до 1, длина всей оси = 2.  
Длина двух целевых отрезков = 0.2 + 0.2 = 0.4.  
Значит класс 1 встречается примерно в **20%** случаев, класс 0 — в **80%**.

Если ничего не делать, сеть может всегда отвечать 0 и получить accuracy около 80%, почти не выучив диапазоны. Это плохая модель, хотя «точность» выглядит высокой.

Что сделано:

1. **Oversampling** (`balance_classes`). Меньший класс (единицы) копируем случайно, пока примеров класса 1 не станет столько же, сколько класса 0. Учим сеть на выборке 50/50.
2. **Веса классов** (`class_weights`). В формуле ошибки редкий класс умножается на больший вес:  
   `w = N / (2 * N_класса)`.  
   После oversampling веса почти равны 1, но если баланс чуть нарушится, ошибка всё равно не даст забыть редкий класс.

Важно: **тест идёт без oversampling**, на исходном дисбалансе. Так видно, что сеть работает в реальной ситуации, а не только на «накрученной» обучающей выборке.


- **recall** — какую долю настоящих единиц сеть нашла (у нас близко к 1);
- **precision** — когда сказала 1, как часто это правда;
- **F1** — среднее гармонии precision и recall;
- **матрица ошибок** TN / FP / FN / TP.

## Описание каждой функции

### `in_target_range(x)`

**Что делает:** для каждого `x` проверяет, лежит ли он хотя бы в одном из двух диапазонов.  
**Возвращает:** массив True/False (потом это становится 1/0).  
**Зачем:** это «учитель» — правильный ответ, с которым сравниваем сеть. Сама сеть диапазоны наизусть не знает, она видит только пары (x, ответ).

### `make_dataset(n_samples, rng)`

**Что делает:** равномерно бросает `n_samples` точек на `[-1, 1]` и размечает их через `in_target_range`.  
**Возвращает:** `x` формы `(n, 1)` и `y` той же формы.  
**Зачем:** получить обучающую или тестовую выборку.

### `balance_classes(x, y, rng)`

**Что делает:** считает индексы класса 1 и класса 0. У какого класса меньше примеров — тот добирает копиями (`replace=True`). Потом перемешивает.  
**Возвращает:** новую выборку с равным числом 0 и 1.  
**Зачем:** борьба с дисбалансом на этапе данных.

### `class_weights(y)`

**Что делает:** считает вес каждого примера обратно частоте его класса.  
**Возвращает:** столбец весов той же длины, что `y`.  
**Зачем:** борьба с дисбалансом на этапе функции потерь.

### Класс `MLP` — сама сеть

Хранит веса и смещения трёх слоёв:

- `W1` размер 1×4, `b1` — вход → 4 скрытых
- `W2` размер 4×2, `b2` — 4 → 2 скрытых
- `W3` размер 2×1, `b3` — 2 → 1 выход

Плюс «скорости» `vW`, `vb` для метода момента.

Инициализация весов: нормальное распределение со std `sqrt(1 / число_входов_слоя)`. Это Xavier-инициализация, она хорошо подходит для tanh: веса не слишком большие, иначе tanh сразу насыщается в ±1 и градиент почти ноль.

#### `MLP.__init__(rng)`

Создаёт случайные веса, нулевые смещения и нулевые буферы момента.

#### `MLP.forward(x)`

Прямой проход:

```
z1 = x · W1 + b1
a1 = tanh(z1)

z2 = a1 · W2 + b2
a2 = tanh(z2)

z3 = a2 · W3 + b3
a3 = tanh(z3)
```

**Возвращает:** выход `a3` и `cache` (промежуточные активации), чтобы потом быстро посчитать градиенты.  
 «forward — это как сеть считает ответ на входе».

#### `MLP.backward(y, weights, cache, lr, momentum)`

Обратный проход:

1. Ошибка на выходе: насколько `a3` отличается от цели `y`, с учётом весов классов. Берём производную MSE.
2. Умножаем на производную tanh: `1 - a^2`.
3. Считаем градиенты весов и смещений каждого слоя, идя **с конца к началу**.
4. Обновляем веса с моментом:  
   `v = momentum * v - lr * градиент`  
   `вес = вес + v`

`lr` — скорость обучения (0.05).  
`momentum` — 0.9, то есть 90% предыдущего шага сохраняется.

 «backward — сеть понимает, кто виноват в ошибке, и чуть меняет веса».

#### `MLP.predict_proba(x)`

Только forward, без обучения. Возвращает непрерывный выход tanh (от -1 до 1).

#### `MLP.predict(x, threshold=0)`

Сравнивает выход с порогом 0 и даёт целое 0 или 1. Это уже ответ лабораторной.

### `train(model, x, y, epochs, lr, momentum)`

Цикл обучения:
- 4000 раз прогоняем всю выборку (пакетный градиентный спуск, batch = вся выборка);
- считаем взвешенный MSE;
- вызываем `backward`;
- каждые 500 эпох печатаем ошибку и accuracy.

Цели `y` здесь уже **со знаком** (-1/+1). Accuracy внутри цикла сравнивает знак выхода со знаком цели.

**Возвращает:** список ошибок по эпохам для графика.

### `metrics(y_true, y_pred)`

Считает:
- TP — сказали 1, и это правда 1
- TN — сказали 0, и это правда 0
- FP — сказали 1, а надо было 0 (ложная тревога)
- FN — сказали 0, а надо было 1 (пропуск диапазона)

Дальше:
- accuracy = (TP + TN) / N
- precision = TP / (TP + FP)
- recall = TP / (TP + FN)
- F1 = 2 * precision * recall / (precision + recall)

**Возвращает:** словарь с этими числами и матрицей `[[TN, FP], [FN, TP]]`.

### `plot_results(model, history, x_raw, y_raw)`

Рисует 4 графика и сохраняет `result.png`.

1. **Классы до балансировки** — гистограмма 0 и 1 на сырых данных. Показывает дисбаланс (~80% / ~20%).
2. **Ошибка обучения** — как падает MSE. Если кривая падает и выходит на плато — сеть обучилась.
3. **Истина и выход tanh** — синяя «ступенька» правильной разметки и оранжевый непрерывный выход сети. На границах tanh не идеален, это нормально.
4. **Классификация с порогом 0** — уже ответы 0/1. Должны совпасть с двумя окнами диапазонов.

### `interactive_predict(model)`

После обучения спрашивает `x =` в консоли. Можно писать `0.6` или `0,6`. Пустая строка или `q` — выход. Печатает ответ сети, значение tanh и правильный ответ по правилу диапазона (чтобы сразу видеть, ошиблась сеть или нет).

### `main()`

Собирает весь сценарий: данные → баланс → обучение → тест → графики → ввод пользователя.
